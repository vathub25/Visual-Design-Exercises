# Visual-Design-Exercises
A collection of creative design exercises from my first semester, exploring fundamental design principles, visual composition, and creative thinking.

## About

These exercises were completed as part of my Media and Communication Informatics studies at Reutlingen University.

Throughout the semester, I worked on different topics, including:

- Typography and color theory
- Logo and layout design
- UI/UX and web design
- Illustration and pixel animation
- Photography and image editing
- Art and design history

## Tools

Figma, Adobe Photoshop, Adobe Illustrator
